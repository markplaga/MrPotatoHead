# 🥔 SPUDVERSE 3D — Freeform Potato Studio

Build your own hilarious 3D potato character directly in the browser.

**Play:** Open `index.html` in any modern browser. The app is entirely self-contained and does not need npm, a build step, a database, or an account.

## Features

- WebGL 3D potato with a Canvas 2D fallback
- Drag individual eyes, noses, mouths, hats, ears, arms, shoes, glasses, and accessories anywhere on the potato
- Rotate the view, zoom, resize, flip, duplicate, and remove pieces
- Six potato skins, backgrounds, and character presets
- Randomize characters; undo and redo
- Save designs locally, export/import JSON, and capture PNG snapshots
- Built-in music controls plus the ability to load your own audio file
- Desktop, mobile, and tablet support, including touch controls

## Publish with GitHub Pages

In this repository, go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save.

Once GitHub Pages finishes deploying, the game should be available at:
https://markplaga.github.io/MrPotatoHead/

If Pages is not configured, the GitHub repository still contains all source code.

## Controls

Tap a part from the toy box to add it, then drag the part to move it. Drag empty space to rotate the character. Pinch or use the mouse wheel to zoom. Select a part to use the editing controls.

Keyboard shortcuts: `Ctrl/Cmd + Z` for undo, `Ctrl/Cmd + Shift + Z` for redo, `Delete` to remove a selected part, `R` to randomize, and `F` to face forward.

This is an original potato character builder and is not affiliated with any commercial toy brand.
